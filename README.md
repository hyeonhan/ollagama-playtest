# 올라가마 (Carry Up) 플레이테스트

2~4명이 가마 하나를 함께 메고 산꼭대기까지 오르는 협동 게임의 **Windows 테스트 빌드** 배포용 저장소입니다.
떨어지면 처음부터 다시 오르고, 횟수 제한은 없습니다. (소스 코드는 여기에 없습니다.)

## 내려받기

**[최신 빌드 받기 (Releases)](https://github.com/hyeonhan/ollagama-playtest/releases/latest)**: `ollagama-<버전>-windows.zip`을 받습니다.

## 실행하기

1. zip 파일을 마우스 오른쪽 버튼으로 누르고 **압축 풀기**를 고릅니다. zip 창 안에서 바로 실행하면 열리지 않습니다.
2. 압축을 푼 폴더의 `ollagama.exe`를 실행합니다. `ollagama.pck`(게임 데이터)가 같은 폴더에 있어야 합니다.
3. 파란 **Windows의 PC 보호** 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 아직 코드 서명을 하지 않은 테스트 빌드라서 뜨는 경고입니다.
4. [방 만들기]나 [참가]를 누를 때 **Windows 보안 경고**(방화벽) 창이 뜨면 **액세스 허용**을 누릅니다.
   Radmin VPN으로 같이 할 거라면 **공용 네트워크**에도 체크합니다.

필요 사양: 64비트 Windows 10 또는 11, Vulkan을 지원하는 그래픽카드(대략 2015년 이후 제품).

## 조작

| 동작 | 키보드·마우스 | 게임패드 |
| --- | --- | --- |
| 이동 / 시점 | W A S D / 마우스 | 왼쪽 스틱 / 오른쪽 스틱 |
| 점프 | Space | A |
| 가마 잡기 (누르고 있는 동안) | 마우스 왼쪽 버튼 또는 E | RT |
| 이모트 | 1 2 3 4 | 방향 버튼 |
| 마우스 풀기 | Esc | |
| 전체 화면 | F11 또는 Alt+Enter | |

## 같이 하기

**혼자 해 보기**: 로비에서 [혼자 하기]. 맛보기용입니다.

**같은 공유기(집·사무실)**
1. 한 사람이 [방 만들기]를 누르면 메뉴 아래에 `hosting on 192.168.0.12:24565`처럼 주소가 나옵니다.
2. 나머지 사람은 [주소] 칸에 그 주소를 넣고 [참가]를 누릅니다.
3. 모두 [준비]를 누르면 방을 만든 사람이 [출발]을 누릅니다(2명 이상). 산과 "오늘의 변형"은 방장이 고릅니다.

**멀리 떨어진 친구**: 이번 빌드는 Steam 친구 초대가 아직 없고 주소로 직접 접속합니다. 무료 가상 랜 프로그램
[Radmin VPN](https://www.radmin-vpn.com/)을 쓰는 것이 가장 쉽습니다.
1. 모두 Radmin VPN을 설치합니다. 방장이 Network → Create Network로 이름과 비밀번호를 정하고, 나머지는
   Network → Join Network로 들어옵니다.
2. 게임에서 방을 만들면 `hosting on` 뒤에 26으로 시작하는 주소가 함께 나옵니다. 친구들은 그 `26.x.x.x:24565`로 참가합니다.
3. 접속이 안 되면 방장 PC의 방화벽에서 올라가마를 허용했는지 확인합니다(제어판 → Windows Defender 방화벽 →
   "앱이 Windows Defender 방화벽을 통과하도록 허용"에서 ollagama의 개인·공용에 체크).

공유기 설정에 익숙하다면 방장 공유기에서 UDP 24565 포트를 포워딩해도 됩니다.

## 피드백

빌드를 보내 준 사람에게 알려 주세요. 짧게 적어 주셔도 큰 도움이 됩니다.

- 몇 명이서 했는지, 어느 산까지 올랐는지
- 재미있었던 순간, 답답하거나 억울했던 순간
- 버그: 무엇을 하다가 어떻게 됐는지(가능하면 스크린샷이나 짧은 영상)
- 로비 오른쪽 아래의 버전과 그래픽카드 이름

게임이 꺼지거나 이상하면 로그 파일도 보내 주세요. Win+R → `%APPDATA%\Ollagama\logs` → `godot.log`.

## 알려진 점

- Windows 실제 기기에서 처음 돌려 보는 빌드입니다. 화면이 깨지거나 너무 느리면 꼭 알려 주세요.
- 음악과 효과음은 AI(Stable Audio)로 만들었습니다.
- 지우려면 압축을 푼 폴더와 `%APPDATA%\Ollagama` 폴더를 지우면 됩니다.
